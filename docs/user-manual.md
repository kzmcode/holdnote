# HoldNote ユーザーマニュアル

HoldNote は、**キーを押している間だけ録音し、話した内容を文字にして Google Drive に保存する** Mac アプリです。
思いついたことを、作業中のアプリから手を離さずにメモできます。

```
 ⌃⌥R を押し続けて話す  →  キーを離す  →  Mac の中で文字起こし  →  Google Drive に .md ファイルで保存
```

- 音声は **Mac の中だけで** 文字にします。音声データがインターネットに送られることはありません。
- Google Drive に送られるのは、文字起こしした結果のテキスト（Markdown ファイル）だけです。

## 1. 必要なもの

| 必要なもの | 説明 |
|---|---|
| Apple Silicon の Mac（M1 以降） | Intel Mac には対応していません |
| macOS 14（Sonoma）以降 | |
| [Homebrew](https://brew.sh/ja/) | インストールに使います |
| Google アカウント | 保存先の Google Drive として使います |
| Google Cloud の OAuth クライアント | Google Drive に保存するために **最初に1回だけ** 作ります（[3-3](#3-3-google-drive-と連携する) で説明） |
| 約 200MB の空き容量 | アプリ本体と音声認識モデル（base）の分 |

## 2. インストール

### 2-1. Homebrew でインストール

ターミナルを開いて、次を実行します。

```bash
brew install --cask kzmcode/tap/holdnote
```

> Homebrew が入っていない場合は、先に [Homebrew の公式サイト](https://brew.sh/ja/) の手順でインストールしてください。

### 2-2. 初めて起動する（Gatekeeper の許可）

HoldNote は Apple の公証を受けていないため、初回は macOS に起動をブロックされます。次の手順で許可してください。

1. 「アプリケーション」フォルダの **HoldNote** を開く
2. 「開けません」と表示されたら、いったん閉じる
3. **システム設定 → プライバシーとセキュリティ** を開き、下の方にある「セキュリティ」欄の **「このまま開く」** を押す
4. 確認画面で「開く」を押す

> 一度許可すれば、次からは普通に起動できます。Gatekeeper を無効にする必要はありません。

起動すると、画面右上の **メニューバーにマイクのアイコン** が表示されます。HoldNote は Dock には表示されません。
初回は設定画面が自動で開きます。

## 3. 初期設定（最初の1回だけ）

設定は次の3ステップです。設定画面は、メニューバーのマイクアイコン →「**設定…**」でいつでも開けます。

| ステップ | 内容 | 目安時間 |
|---|---|---|
| [3-1](#3-1-マイクを確認する) | マイクを確認する | 1 分 |
| [3-2](#3-2-音声認識モデルをダウンロードする) | 音声認識モデルをダウンロードする | 1〜3 分 |
| [3-3](#3-3-google-drive-と連携する) | Google Drive と連携する | 15〜20 分（初回のみ） |

### 3-1. マイクを確認する

1. 「マイクへのアクセスを求めています」と表示されたら **「許可」** を押します。
2. 設定画面の **「一般」タブ** で、マイク欄を確認します。
   ```
   マイク: 許可済み ／ 入力: MacBook Proのマイク
   ```
   - 「拒否されています」と出ている場合 → **システム設定 → プライバシーとセキュリティ → マイク** で HoldNote をオンにします。
   - 「入力:」が使いたいマイクでない場合 → **システム設定 → サウンド → 入力** でマイクを選びます。
     特に **BlackHole** などの仮想オーディオ機器が選ばれていると、音が入りません。

### 3-2. 音声認識モデルをダウンロードする

1. 設定画面の **「音声認識」タブ** を開きます。
2. モデルが **base** になっていることを確認して、**「モデルをダウンロード」** を押します（約 150MB）。
3. 状態が「**導入済み**」になれば完了です。

| モデル | サイズ | 特徴 |
|---|---|---|
| base（おすすめ） | 約 150MB | 速い。普段のメモには十分な精度 |
| small | 約 490MB | 精度が高いが、文字起こしに時間がかかる |

> 文字起こしエンジン（whisper.cpp）はアプリに同梱されているので、別途インストールする必要はありません。

### 3-3. Google Drive と連携する

HoldNote が Google Drive にファイルを保存するには、**Google Cloud で「OAuth クライアント」を1つ作る** 必要があります。
少し手順が多いですが、最初の1回だけです。作ったクライアントは、自分の他の Mac でも使い回せます。

**(1) OAuth クライアントを作る** → 詳しい手順：[Google Cloud の準備](google-cloud-setup.md)

ここで **クライアント ID** と **クライアント シークレット** の2つを手に入れます。

**(2) HoldNote に入力する**

1. 設定画面の **「Google Drive」タブ** を開きます。
2. クライアント ID とクライアント シークレットを貼り付けて（⌘V）、**「保存」** を押します。

**(3) Google アカウントに接続する**

1. **「Googleに接続」** を押すと、ブラウザが開きます。
2. Google アカウントを選び、HoldNote へのアクセスを **許可** します。
   - 「このアプリは Google で確認されていません」と表示されたら、「詳細」→「HoldNote（安全ではないページ）に移動」で進みます。自分で作ったクライアントなので問題ありません。
3. 「認証が完了しました」と表示されたら、ブラウザのタブは閉じて構いません。

**(4) 保存先フォルダを選ぶ**

1. **「保存先フォルダを選択」** を押すと、ブラウザで Google Drive のフォルダ選択画面が開きます。
2. メモを保存したいフォルダを選びます（あらかじめ Google Drive で「音声メモ」などのフォルダを作っておくと便利です）。
3. 設定画面に、選んだフォルダ名が表示されます。

> HoldNote がアクセスできるのは、**ここで選んだフォルダと、HoldNote が作ったファイルだけ** です。Google Drive の他のファイルは見えません。

**(5) 保存テスト**

**「保存テスト」** を押して「**保存テストに成功しました**」と表示されれば、準備は完了です（テスト用のファイルを作ってすぐ削除します）。

## 4. 使い方

### 4-1. 録音する

1. どのアプリを使っていても、**`⌃⌥R`（Control + Option + R）を押し続けます**。
2. 画面上部に録音中の表示が出たら、**話します**。
3. 話し終わったら **キーを離します**。

あとは自動で、文字起こし → Google Drive への保存まで進みます。保存が終わると「Google Driveに保存しました」と表示されます。

- 0.3 秒未満の録音と、無音の録音は保存されません。
- 1回の録音は最長 10 分です。
- 文字起こしをしている間も、次の録音ができます。

### 4-2. キーを使わずに録音する

メニューバーのマイクアイコン → **「録音開始」** で録音を始め、**「録音停止」** で止めます。

### 4-3. 保存したメモを開く

- 直前のメモ：メニューバーのマイクアイコン → **「最後のメモを開く」**（Google Drive がブラウザで開きます）
- 過去のメモ：メニューバー →「**履歴…**」→ 各行の **「開く」**

### 4-4. ショートカットを変える

1. 設定画面の **「一般」タブ** で、「録音ホットキー」の欄（`⌃⌥R` と表示されている欄）をクリックします。
2. 枠が青くなったら、**使いたいキーの組み合わせを押します**（例：`⌃⌥M`）。その場で登録されます。
   - `⌃` `⌥` `⇧` `⌘` のどれかを必ず含めてください。
   - **Esc** を押すと、変更せずに終わります。
   - 他のアプリで使われているキーは登録できません。その場合は赤字で表示され、元のキーのまま残ります。

## 5. 画面の見方

### 5-1. 録音中・処理中の表示（画面上部）

録音中や保存の結果は、画面上部の中央に小さく表示されます。この表示はクリックしても反応せず、作業中のアプリの操作を邪魔しません。

| 表示 | 色 | 意味 |
|---|---|---|
| 🎙 **録音中** 00:12 ＋ 音量バー | 赤 | 録音しています。キーを離すと終わります |
| **文字起こし中…** | 青 | Mac の中で文字にしています |
| **保存中…** | 青 | Google Drive に送っています |
| ✓ **Google Driveに保存しました** | 緑 | 保存が完了しました |
| ⏱ **保存待ち** | 黄 | ネットワークの問題などで、あとで自動的に再送します |
| ⚠ **保存できませんでした** ＋ 理由 | 赤 | 対応が必要です（[10章](#10-困ったとき)） |
| ⓘ 録音が短すぎるため破棄しました など | 灰 | お知らせ |

### 5-2. メニューバー

マイクアイコンをクリックすると、次のメニューが出ます。

| メニュー | 内容 |
|---|---|
| 状態: 待機 など | 今の状態（待機 / 録音中 / 文字起こし中 / 保存中 / 保存待ち / 要対応） |
| 録音開始 / 録音停止 | キーを使わずに録音します |
| 最後のメモを開く | 直前に保存したメモを Google Drive で開きます |
| 未保存: N件 | まだ Google Drive に保存できていないメモの数 |
| 履歴… | 過去のメモの一覧を開きます |
| すべて再試行 | 保存できなかったメモを、もう一度送ります |
| 設定… | 設定画面を開きます |
| 終了 | HoldNote を終了します |

録音中は、アイコンが赤くなり、横に「● 録音中」と表示されます。保存待ちのメモがあるときは「保存待ち N」と表示されます。

### 5-3. 履歴

設定画面の **「履歴」タブ** では、録音したメモの一覧と状態を確認できます。

- **開く**：Google Drive のファイルを開きます
- **再試行**：保存できなかったメモをもう一度送ります
- **削除**：この Mac から記録を削除します（Google Drive のファイルは消えません）

## 6. 設定画面の項目

| タブ | 項目 | 説明 |
|---|---|---|
| 一般 | 録音ホットキー | 録音に使うキー（[4-4](#4-4-ショートカットを変える)） |
| | 録音テスト | 押すたびに録音の開始・停止を切り替えます |
| | マイク | マイクの許可状態と、使っている入力機器 |
| | ログイン時に起動 | Mac にログインしたとき、自動で HoldNote を起動します（初期設定：オン） |
| | 音声ファイルの保持時間 | 保存が終わった録音を、この Mac に残しておく時間（初期設定：24 時間） |
| | ローカルのメモ・音声をすべて削除 | この Mac にある録音・メモ・履歴をすべて消します。**Google Drive のファイルは消えません** |
| Google Drive | クライアント ID / シークレット | [3-3](#3-3-google-drive-と連携する) で作ったもの |
| | Googleに接続 / 再認証 | Google アカウントとの接続 |
| | 連携を解除 | 接続を解除し、この Mac から認証情報を削除します。**Google Drive のファイルは消えません** |
| | 保存先フォルダを選択 | メモを保存するフォルダ |
| | 保存テスト | 保存できるか確認します |
| 音声認識 | モデル | base / small（[3-2](#3-2-音声認識モデルをダウンロードする)） |
| | モデルをダウンロード | 選んだモデルを取得します |
| | whisper-cli | 文字起こしエンジンの場所（通常は変更不要） |
| 履歴 | — | [5-3](#5-3-履歴) |

> 保存先フォルダを変えても、すでに録音済みで保存待ちのメモは、**録音したときのフォルダ** に保存されます。

## 7. 保存されるファイル

Google Drive には、録音ごとに1つの Markdown（`.md`）ファイルが保存されます。

- ファイル名：`録音開始日時_ID.md`（例：`2026-10-13_17-30-05_a1b2c3.md`）
- 中身の例：

```markdown
---
created_at: 2026-10-13T17:30:05+09:00
duration_seconds: 18.4
language: ja
source: HoldNote
transcription_engine: whisper.cpp
save_mode: drive_api
---

# 音声メモ（2026-10-13 17:30）

## 文字起こし

この内容を来週の会議で共有したい。
```

文字起こしは、話した内容をそのまま文字にします。要約や修正はしません。

## 8. プライバシーとデータの保存場所

- 音声は **Mac の中だけで** 処理し、インターネットには送りません。
- Google Drive に送るのは、文字起こしした Markdown ファイルだけです。
- Google の認証情報は、macOS の **キーチェーン** に安全に保存します。
- ログには、文字起こしの内容や認証情報を記録しません。

この Mac に保存されるデータは次のとおりです。

| データ | 場所 |
|---|---|
| 設定 | `~/Library/Application Support/HoldNote/settings.toml` |
| 録音した音声 | `~/Library/Application Support/HoldNote/audio/`（保存完了から 24 時間後に自動削除） |
| 文字起こしした Markdown | `~/Library/Application Support/HoldNote/queue/` |
| 音声認識モデル | `~/Library/Application Support/HoldNote/models/` |
| ログ | `~/Library/Application Support/HoldNote/logs/holdnote.log` |
| Google の認証情報 | キーチェーン（`io.github.holdnote.HoldNote`） |

> 保存できなかったメモの音声は、保存できるまで削除されません。

## 9. アップデート・アンインストール

```bash
brew upgrade --cask kzmcode/tap/holdnote          # 最新版に更新
brew uninstall --cask kzmcode/tap/holdnote        # アプリを削除（設定・履歴は残る）
brew uninstall --zap --cask kzmcode/tap/holdnote  # 設定・履歴・録音もすべて削除
```

- アップデート後、マイクの許可をもう一度求められることがあります。「許可」を押してください。
- 完全に削除したい場合は、アンインストールの **前に** 設定画面で **「連携を解除」** を押してください。キーチェーンの認証情報は `--zap` では消えません。

## 10. 困ったとき

### まず診断コマンドを実行する

ターミナルで次を実行すると、マイク・音声認識・Google Drive の設定をまとめてチェックできます。

```bash
/Applications/HoldNote.app/Contents/MacOS/holdnote --doctor
```

`✘`（問題）や `⚠`（注意）の行に、直し方のヒントが表示されます。設定やファイルは変更しないので、何度実行しても安全です。

### よくある質問

| 症状 | 原因と対処 |
|---|---|
| 「開発元を検証できないため開けません」と出る | [2-2](#2-2-初めて起動するgatekeeper-の許可) の手順で許可してください |
| 「音声が入力されていません（入力: BlackHole …）」と出る | 入力機器が仮想デバイスになっています。**システム設定 → サウンド → 入力** でマイクを選んでください |
| 録音しても「無音のため破棄しました」と出る | マイクが選ばれているか、マイクの音量が小さすぎないかを確認してください |
| 「マイクへのアクセスが許可されていません」と出る | **システム設定 → プライバシーとセキュリティ → マイク** で HoldNote をオンにしてください。アップデート後に起きやすい症状です |
| キーを押しても録音が始まらない | 他のアプリが同じキーを使っている可能性があります。[4-4](#4-4-ショートカットを変える) で別のキーに変えてください。メニューの「録音開始」でも録音できます |
| 「音声認識モデルがありません」と出る | [3-2](#3-2-音声認識モデルをダウンロードする) でモデルをダウンロードしてください |
| 「Googleの再認証が必要です」と出る | 設定画面「Google Drive」タブで **「再認証」** を押してから、メニューの **「すべて再試行」** を押してください。OAuth クライアントが「テスト中」のままだと、**7 日ごと** に再認証が必要になります（[Google Cloud の準備 手順 5](google-cloud-setup.md#手順-5-公開ステータスを決める)） |
| 「保存先フォルダにアクセスできません」と出る | 保存先フォルダが削除・移動された可能性があります。**「保存先フォルダを選択」** で選び直してから、履歴の **「再試行」** を押してください |
| 「保存待ち」のまま進まない | オフラインの間は保存待ちになり、つながると自動で再送します（間隔は最大 30 分）。すぐ送りたいときはメニューの **「すべて再試行」** を押してください |
| 通知が表示されない | **システム設定 → 通知** で「スクリプトエディタ」の通知を許可してください |
| `brew install` で「already an App at …」と出る | 手動で入れた HoldNote が残っています。「アプリケーション」フォルダから削除してから、もう一度実行してください |

### 問題を報告する

解決しない場合は、[GitHub の Issues](https://github.com/kzmcode/holdnote/issues) で報告してください。
次の情報があると原因を調べやすくなります。

- `holdnote --doctor` の出力
- ログの最後の部分：`tail -50 ~/Library/Application\ Support/HoldNote/logs/holdnote.log`
  （文字起こしの内容や認証情報は含まれていません）
- 何をしたときに、どうなったか
